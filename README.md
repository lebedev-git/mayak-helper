# Помощник МАЯК

Расширение Chrome для тренажёра МАЯК-ОКО: показывает прямо на странице сервиса, куда нажать и что сделать
дальше. Сервисы: Suno, Qwen, Gamma, Z.ai, Renderforest, Audiocleaner, PixVerse. Данные никуда не отправляет.

Здесь всегда последняя версия. В Chrome Web Store она появляется позже: каждое обновление там проверяют
несколько дней.

## Установка, один раз

**Командой.** Открыть PowerShell и выполнить:

```
irm https://raw.githubusercontent.com/lebedev-git/mayak-helper/main/install.ps1 | iex
```

Команда скачает помощника в папку `%LOCALAPPDATA%\MayakHelper`, скопирует путь к ней и откроет страницу
расширений Chrome. Там включить "Режим разработчика" (справа вверху), нажать "Загрузить распакованное
расширение" и вставить путь (Ctrl+V).

**Вручную.** Скачать [ZIP](https://raw.githubusercontent.com/lebedev-git/mayak-helper/main/mayak-helper.zip),
распаковать в постоянную папку (не во "Временные"), открыть `chrome://extensions`, включить "Режим
разработчика", нажать "Загрузить распакованное расширение" и выбрать папку, где лежит `manifest.json`.

## Компьютеры площадки: без рук

Когда помощник опубликован в Chrome Web Store, его можно поставить на компьютер так, что Chrome сам его
установит, сам обновит и не даст удалить случайно. Выполнить в PowerShell (Windows спросит права
администратора):

```
irm https://raw.githubusercontent.com/lebedev-git/mayak-helper/main/policy-install.ps1 | iex
```

Затем закрыть Chrome полностью и открыть снова: через минуту помощник появится сам. В меню Chrome будет
строка "Управляется вашей организацией", это и есть эта настройка. Копию из папки скрипт удаляет, чтобы не
было двух помощников сразу. Проверить: адрес `chrome://policy`, строка ExtensionInstallForcelist.

Убрать:

```
irm https://raw.githubusercontent.com/lebedev-git/mayak-helper/main/policy-remove.ps1 | iex
```

Пока расширение не опубликовано в магазине, это не сработает: на обычных компьютерах Chrome так ставит
только расширения из магазина.

## Обновление

Снова выполнить команду (или заменить папку файлами из нового ZIP), затем на странице `chrome://extensions`
нажать круглую стрелку у "Помощник МАЯК" и перезагрузить вкладки сервисов.

Номер версии: в `manifest.json` и на странице расширений.
