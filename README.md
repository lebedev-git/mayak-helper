# Помощник МАЯК

Расширение Chrome для тренажёра МАЯК-ОКО: показывает прямо на странице сервиса, куда нажать и что сделать
дальше. Сервисы: Suno, Qwen, Gamma, Z.ai, Renderforest, Audiocleaner, Any2text, PixVerse. Данные никуда не отправляет.

Здесь всегда последняя версия.

## Установка, один раз на компьютер

1. Скачать архив: [mayak-helper.zip](https://raw.githubusercontent.com/lebedev-git/mayak-helper/main/mayak-helper.zip).
2. Распаковать его в постоянную папку, например в "Документы": правый клик по архиву, "Извлечь все".
   Папку потом не удалять: Chrome берёт помощника из неё.
3. В Chrome открыть адрес `chrome://extensions` и справа вверху включить "Режим разработчика".
4. Нажать "Загрузить распакованное расширение" и выбрать распакованную папку (в ней лежит `manifest.json`).
   Само окно показывает только папки: если видно только архив, его ещё не распаковали (шаг 2).
5. Проверить: открыть suno.com, внизу появится капсула с маяком.

## Обновление

Скачать архив заново, распаковать в ту же папку с заменой файлов, затем на странице `chrome://extensions`
нажать круглую стрелку у "Помощник МАЯК" и перезагрузить вкладки сервисов.

Номер версии: на странице `chrome://extensions`, в карточке помощника.

## Командой (для тех, кто знаком с PowerShell)

Шаги 1-2 одной командой: архив скачается и распакуется в `%LOCALAPPDATA%\MayakHelper`, путь к папке
скопируется, откроется страница расширений. Дальше шаги 3-5.

```
irm https://raw.githubusercontent.com/lebedev-git/mayak-helper/main/install.ps1 | iex
```
